# Manhattan Vacation Rental Market Analysis

## Project Overview
Analyzed Airbnb listing data to provide investment recommendations on which Manhattan neighborhoods and property types generate the highest vacation rental revenue, using Google Sheets.

## Live Project
[View the full analysis in Google Sheets](https://docs.google.com/spreadsheets/d/17XeRCidGxU4oCj-2EL0xA3wotuy7X921/edit?usp=drive_link)

## Key Findings
- **Top Neighborhoods** — Identified the top 10 most attractive Manhattan neighborhoods for vacation rental investment using pivot tables analyzing review frequency and SUMIF revenue calculations.
- **Optimal Property Size** — Determined that 1-bedroom units were the optimal property size in 9 of the top 10 neighborhoods, with the top-earning listing generating $29,940 in 30-day revenue.
- **Executive Recommendations** — Delivered a structured spreadsheet with a Table of Contents, Executive Summary, bar charts, and clearly documented analytical assumptions to support investment decisions.

## Tools Used
| Tool | Purpose |
|------|---------|
| Google Sheets | Pivot tables, revenue calculations, bar charts, data organization |
| SUMIF | Calculating estimated revenue per listing and neighborhood |
| Pivot Tables | Aggregating review frequency and revenue across neighborhoods |

## Dataset
Airbnb listing data for Manhattan — includes neighborhood, property type, number of bedrooms, review frequency, and pricing information.
